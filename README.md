본 저장소는 생성형 언어 모델과 정규식 기반 휴리스틱을 활용하여 한국어 질문 라벨링 데이터 생성 및 문장 내 시간 제약(Time Constraint) 추출 및 정규화를 수행한 연구 프로젝트 결과물입니다.

**📋 1. 라벨별 질문 생성**

개요: 생성형 언어 모델을 활용하여 성격에 따라 두 가지 유형(changed, unchanged)으로 구분되는 한국어 질문을 각 라벨별 5,000건씩 생성하는 과제입니다.

🔹 질문 유형 정의

changed: 시간이 지나면 답이 달라질 수 있는 질문

unchanged: 언제 물어봐도 동일한 답을 가지는 질문

🔹 사용 모델 및 환경

Model: Qwen3-32B (4bit 양자화 적용)

🔹 주요 수행 과정

프롬프트 설계: 도메인별 예시 질문과 라벨 정의를 포함하여 모델이 타깃 유형의 질문을 생성하도록 유도

텍스트 정제: 생성된 질문에서 기호, 띄어쓰기 오류, 오타를 교정하고 종결 어미 및 한글 비율을 검사하여 유효하지 않은 문장 제외

휴리스틱 검증: 시간 표현(현재, 올해, 최근 등) 및 변동성 지표(환율, 주가 등) 포함 여부를 규칙 기반으로 재판별

🔹 한계 및 향후 개선 방향

라벨별 질문을 모델이 정확히 구분하지 못하는 경우가 존재했습니다. 복잡한 표현이나 예외적인 질문에서 발생하는 분류 오류를 보완하기 위해 프롬프트 구조 개선 및 별도 분류기 도입이 필요합니다.

**⏱️ 2. 문장 내 시간 제약 추출**

개요: 한국어 위키백과 문장(kowiki_sents)에서 시간 제약을 추출하고, 이를 수식어구 - timestamp - temporal relation 형태로 정규화하여 패턴 사전을 구축하는 과제입니다.

🔹 사용 모델 및 환경

Model: Qwen3-32B (4bit 양자화 적용)

Environment: Python Script (extraction_code.py, temporal_mapper.py)

🔹 단계별 파이프라인

1단계: 시간 제약 추출 (extraction_code.py ➔ extraction_results.jsonl)

kowiki_sents 중 100,000문장을 무작위로 선택

모델이 JSON 형식으로 시간 표현을 추출하도록 프롬프트 설계

정규식(Regex) 기반 정규화 휴리스틱을 활용하여 범위(예: 2010년~2015년) 및 단일 표현(예: 1970년대, 15세기 초반) 보완

2단계: 패턴 매핑 (temporal_mapper.py ➔ extraction_results_out.jsonl)

추출 결과를 수식어구 - timestamp - temporal relation 키 기준으로 정리

동일 키가 여러 번 등장할 경우 최초 1개만 채택하여 패턴 사전을 단순화

🔹 한계 및 개선 노력

초기에는 프롬프트만으로 추출을 진행하여 표현 누락이 많았습니다. 정규화 휴리스틱을 추가하고 결과를 관찰하여 누락된 관계 표현을 수동 규칙으로 보완하였으나, 사람의 직접 개입이 지속적으로 필요하다는 한계가 있었습니다.
