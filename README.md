📋 1. 라벨별 질문 생성 
개요: 생성형 언어 모델을 활용하여 성격에 따라 두 가지 유형(changed, unchanged)으로 구분되는 한국어 질문을 각 라벨별 5,000건씩 생성하는 과제입니다.
질문 유형 정의
- changed: 시간이 지나면 답이 달라질 수 있는 질문
- unchanged: 언제 물어봐도 동일한 답을 가지는 질문
사용 모델 및 환경: Qwen3-32B (4bit 양자화 적용)
주요 수행 과정
- 프롬프트 설계: 도메인별 예시 질문과 라벨 정의를 포함하여 모델이 타깃 유형의 질문을 생성하도록 유도
- 텍스트 정제: 기호, 띄어쓰기 오류, 오타 교정 및 종결 어미·한글 비율 검사를 통한 유효 문장 필터링
- 휴리스틱 검증: 시간 표현(현재, 올해 등) 및 변동성 지표(환율, 주가 등) 포함 여부를 규칙 기반으로 재판별
한계 및 향후 개선 방향: 복잡한 표현이나 예외적인 질문에서 발생하는 분류 오류를 보완하기 위해 지속적인 프롬프트 개선 및 별도 분류기 도입 필요
